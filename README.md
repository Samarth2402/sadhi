# Samarth × Riddhi — The Unending Story

*One Office. A Thousand Memories. An Unending Story.*

A private, cinematic, and interactive friendship website celebrating the memories, laughter, milestones, and unbreakable bond between Samarth and Riddhi.

## Highlights
- **Cinematic Storytelling:** 9 authentic chapters chronicling our journey from Capermint Technology desks to the future ahead.
- **Scrapbook Design:** Editorial Polaroid frames, washi tapes, handwritten notes, and interactive keepsakes.
- **The Tom & Jerry Chronicles:** Interactive sibling rivalry dial and real banter generator.
- **Private Photo Vault:** Server-side authenticated delivery protecting original photographs.
- **Background Music:** Integrated soundtrack with play/pause controls.
- **Secret Entrance:** Secured with the private passcode.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion & Canvas Confetti
- **Deployment:** Vercel

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run start
```
